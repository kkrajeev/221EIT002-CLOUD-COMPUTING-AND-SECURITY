# Seminar 6 — Virtual machine and hypervisor security

[Back to seminars](README.md) · [Home](../README.md)

**Syllabus section:** VM security
**Slides:** 20-22
**Exam:** CO1 virtualization drawbacks; CO4 virtualization and DR

## Focus
Threats that exist because of virtualization, and how to harden guests and the hypervisor.

## Include
- VM escape, hopping, sprawl
- Snapshot and image theft
- Hypervisor as a high-value target
- Guest hardening and management-plane isolation
- Live-migration security (do not reteach migration steps)

## Example
Compromised imaging-workstation VM sharing a host with the EHR VM.

## Current status
Hardware-assisted virtualization and confidential VMs. Containers: 2 slides only.
