# Seminars — 15 marks

[Back to home](../README.md)

Course: **221EIT002 Cloud Computing and Security**
Outcome: **CO4**. Also PO2 (presentation).

## Format

- **40-45 min talk + 10-15 min questions**
- **20-24 slides** (not 40)
- Suggested split: 2 intro, 12-14 core, 3 example, 2 current status, 2-3 recap/questions
- 1-page outline due 10 days before the talk
- 8-10 references (textbooks + papers/docs)
- Last slide: what the next seminar will take up
- Present in order **1 to 9**

## Common example

An **e-healthcare / hospital records system** on a public cloud (CO4 model question). Every talk applies its topic to this system in 3-4 slides.

## What not to do

Do not spend more than 3 slides on another student's core.
