# Seminar 1 — Cloud security landscape and challenges

[Back to seminars](README.md) · [Home](../README.md)

**Syllabus section:** Security in the cloud — Overview; Cloud Security Challenges
**Slides:** 20-22
**Exam:** CO4 Q1; Part A Q5 Why is it harder to establish security in the cloud?

## Focus
Why cloud security is harder than on-prem. Shared responsibility. A challenge map that later talks will solve.

## Include
- Shared responsibility by IaaS / PaaS / SaaS
- Loss of the old network perimeter
- Multi-tenancy and data location
- Privileged access, compliance, segregation, recovery, forensics, provider viability

## Exclude
IAM design, WAF internals, VM hardening (name them only).

## Example
Hospital EHR on a public cloud: who patches the guest OS vs the application; where PHI may legally sit.

## Current status
Zero Trust and identity as the perimeter. CSA CCM and NIST CSF mappings.

## Starter sources
Rittinghouse Ch. 6; Mather Ch. 2-3; CSA shared-responsibility guidance.
