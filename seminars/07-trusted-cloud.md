# Seminar 7 — Trusted cloud computing

[Back to seminars](README.md) · [Home](../README.md)

**Syllabus section:** Trusted cloud
**Slides:** 20-22
**Exam:** CO4 security objectives for e-healthcare

## Focus
What makes a cloud trusted, not merely available.

## Include
- Trusted-computing characteristics
- Root of trust / measured boot (concept)
- Secure execution environment
- Secure communications
- Attestation so a tenant can check the platform

## Example
Hospital wants proof that the VM handling PHI booted an approved image.

## Current status
TPM/vTPM, Intel TDX, AMD SEV, confidential-computing SKUs.
