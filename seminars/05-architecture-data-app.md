# Seminar 5 — Security architecture: data and application security

[Back to seminars](README.md) · [Home](../README.md)

**Syllabus section:** Security Architecture Design; Data Security; Application Security
**Slides:** 22-24
**Exam:** Part B Q11; Q10(c)(d); CO4 Q2

## Focus
How a cloud security architecture places data and application controls.

## Include
- Control, data, and identity planes
- Data at rest, in transit, in use
- Encryption and key custody; data governance
- Application threats (injection, broken access, insecure APIs)
- Multi-tenant isolation

## Exclude
VM escape (seminar 6); full IAM design (seminar 8).

## Example
Healthcare app: application security, data security, and who holds keys.

## Current status
Envelope encryption, customer-managed keys, confidential computing (mention only).
