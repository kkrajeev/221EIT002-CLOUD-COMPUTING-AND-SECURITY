# Literature survey (review article) — 15 marks

[Back to home](../README.md)

## What this task is

Write a review article from **at least 10 peer-reviewed original publications**. A survey paper may be used to map the field; the review must rest on primary studies. Prefer 2022-2026.

## Method (all topics)

1. Frame 3-4 research questions (scope, methods, metrics, gaps).
2. Note databases, keywords, inclusion/exclusion, years (PRISMA-style).
3. Build **one taxonomy**. Do not write paper-by-paper summaries only.
4. One comparison table: objective, method, dataset, metrics, cloud vs edge, limitations.
5. End with 3 open problems and a one-page candidate project design.
6. Cite IEEE, ACM, Elsevier, Springer, and strong conferences.

## Checklist

- [ ] At least 10 peer-reviewed papers
- [ ] Majority 2022-2026
- [ ] Mix of IEEE / ACM / Elsevier / Springer
- [ ] Comparison table with common metrics
- [ ] Explicit limitations
- [ ] One implementable gap
