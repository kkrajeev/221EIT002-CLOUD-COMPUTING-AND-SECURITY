# Paper-title submissions

Use **Issue #3** to submit titles. Do not edit this folder yourself.

Each literature-survey student lists **at least 10** peer-reviewed papers:

- full title
- authors
- year
- venue (journal or conference)
- DOI or publisher URL

Prefer 2022–2026. Surveys may be used to map the field; the review must rest on primary studies.

After faculty checks a list, it will be copied here as `papers/roll-XX.md`.
