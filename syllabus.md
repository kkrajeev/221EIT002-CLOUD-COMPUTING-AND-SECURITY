## Modules

**Module I — Virtualization (8 hours).** Basics and types. Implementation levels. CPU, memory, and I/O virtualization. Virtual clusters and resource management. Live migration (memory, files, network). Desktop, server, storage, and network virtualization.

**Module II — Cloud computing (6 hours).** System models. NIST reference architecture. Features. IaaS, PaaS, SaaS. Public, private, and hybrid providers.

**Module III — Architecture (6 hours).** Compute and storage clouds. Layered architecture. Design challenges. Inter-cloud resource management. Provisioning and platform deployment. Global exchange of cloud resources.

**Module IV — Paradigms and environments (10 hours, including the security overview).** MapReduce and iterative MapReduce (Twister). Hadoop. Mapping applications and programming support. Google App Engine. Amazon AWS. Eucalyptus, OpenNebula, OpenStack. Security overview, challenges, SaaS security, governance, risk management.

**Module V — Cloud security (10 hours).** SecSDLC. Security monitoring. Security architecture design. Data, application, and VM security. Trusted cloud. IAM and access control (including RBAC). Autonomic security, protection, self-healing. Firewalls and web application firewall.
